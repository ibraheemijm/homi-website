# Homi Website

الموقع العام لمنظومة Homi: تعريف بالتطبيقات ومعلومات التفعيل بالملفات والدعم وروابط التنزيل عند ربط كتالوج الإصدارات.

## التقنية
- Astro 5 وTypeScript.
- CSS متجاوب خفيف.
- جاهز للنشر لاحقًا على Cloudflare Pages.

## التشغيل
```bash
npm install
npm run dev
npm run check
npm run build
```

## الحالة
الموقع يشرح حاليًا إنشاء ملف `.hreq` وإرساله إلى إدارة Homi ثم استيراد ملف `.hlic`. لا يستقبل الموقع ملفات طلبات أو إثباتات دفع في المرحلة الحالية؛ تتم إدارة الطلبات وإصدار التراخيص من لوحة Homi Admin.

هذا المستودع عام مؤقتًا. لا ترفع أسرارًا أو ملفات عملاء أو طلبات تفعيل أو تراخيص حقيقية. لا تنشر قبل ربط النماذج بالمنصة ومراجعة الأمن.
