# Homi Website

الموقع العام لمنظومة Homi: تعريف بالتطبيقات ومعلومات التفعيل والدعم وروابط التنزيل عند ربط كتالوج الإصدارات.

## التقنية
- Astro 5 وTypeScript.
- CSS متجاوب خفيف.
- جاهز للنشر لاحقًا على Cloudflare Pages.

## التشغيل
```bash
npm install
npm run dev
npm run check
npm run build
```

## الحالة
الدفعة الأولى تبني الهيكل والصفحات العامة بالعربية. روابط التنزيل الديناميكية ورفع ملفات `.hreq` ستُربط بعد استكمال API الإصدارات والطلبات والتحقق من الملفات في Homi Platform.

هذا المستودع عام مؤقتًا. لا ترفع أسرارًا أو ملفات عملاء أو طلبات تفعيل أو تراخيص حقيقية. لا تنشر قبل ربط النماذج بالمنصة ومراجعة الأمن.
